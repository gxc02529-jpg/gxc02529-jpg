## 我关注的工程问题

- **可运行**：保留确定性路径，让核心流程可以在本地快速启动和验证。
- **可测试**：用单元测试、回归测试和多 Python 版本 CI 覆盖关键行为。
- **可解释**：明确检索证据、路由决策、审批边界与失败方式。
- **可维护**：固定依赖、扫描已知漏洞，并区分已实现能力与扩展接口。
